# Replication Package - PMC Fiscal Reform and County Economic Growth

This package accompanies the revised manuscript:

**Fiscal Intermediaries, Transfer Delivery, and County Economic Growth: Evidence from China's Province-Managed-County Reform**

## Contents

- `code/stata/`: Stata scripts used for TWFE, CS-DID/event-study, SDID, robustness, missingness, and related checks.
- `code/python/analysis/`: Python scripts for GRF/CATE, DML, honest-DID style sensitivity summaries, multiple-imputation missingness sensitivity, and auxiliary analyses.
- `code/python/visualization/`: Python scripts for figures and table construction.
- `data/analysis/`: partial analysis-ready county-year data used for reviewer replication checks.
- `data/processed/`: derived datasets used by GRF, DML, event-study figures, and table scripts.
- `outputs/tables/`: CSV/XLSX tables generated by the analysis workflow.
- `outputs/figures/`: generated figures and final manuscript figures.
- `docs/`: data notes and variable mapping.

The public GitHub/Zenodo package intentionally excludes the manuscript source, manuscript PDF, and supplementary manuscript files. Those files are handled through the journal submission system rather than the public replication archive.

## Data disclosure note

The package includes a partial analysis-ready panel (`data/analysis/panel_analysis_public.csv` and `.dta`) containing county codes, years, treatment variables, outcomes, fiscal variables, controls, region indicators, and event-study variables. It does **not** include the original yearbook Excel files or hand-compiled raw source sheets. Chinese province/city/county name fields are excluded from the public panel; county identifiers are retained as numeric administrative codes to support replication.

The raw underlying county-year compilation remains available from the corresponding author upon reasonable request after dissertation-related restrictions are cleared, as stated in the manuscript.

## Quick start

1. Open a terminal in this package root.
2. Review `RUN_ORDER.md` for the recommended execution order.
3. For Stata scripts, install the packages listed in `stata_packages.txt`.
4. For Python scripts, install packages listed in `requirements.txt`.
5. Run scripts from the package root so relative paths resolve correctly.

## Round-2 replication note

The package now includes `code/python/analysis/60_multiple_imputation_missingness.py`, which implements a conditional-MAR multiple-imputation sensitivity check for the primary growth outcome and exports `outputs/tables/table_t60_multiple_imputation.csv`. This check complements the IPW and control-function diagnostics in `code/stata/analysis__59_missingness_sensitivity.do`; it is not a missing-not-at-random correction.

## Important reproducibility caveat

Some Stata scripts require user-written commands (`reghdfe`, `csdid`, `drdid`, `sdid`, `eventstudyinteract`, `did2s`, `boottest`, and related dependencies). Exact numerical equality can also depend on package versions and random seeds. Python scripts use fixed random seeds where stochastic estimators are used.
