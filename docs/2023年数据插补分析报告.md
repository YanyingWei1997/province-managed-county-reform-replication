## 二、插补方法评估

### 2.1 方法比较（用2018-2021预测2022验证）

| 方法 | 城镇收入MAPE | 农村收入MAPE | 城乡比MAPE | 偏差 |
|------|-------------|-------------|-----------|------|
| **方法1：线性外推法** | **1.24%** | **1.25%** | **1.34%** | +0.3%/-0.2% |
| 方法2：增长率外推法 | 1.98% | 2.62% | 1.35% | +1.9%/+2.1% |
| 方法3：多元回归预测 | 13.19% | 20.02% | 16.35% | 不稳定 |

**最优方法**：线性外推法（基于县级历史趋势）
- MAPE仅1.2-1.3%，预测精度高
- 偏差接近零，不会系统性高估或低估
- 城乡收入比的误差也很小（1.34%）

### 2.2 线性外推法原理

对每个县 $i$，基于2018-2022年数据拟合线性趋势：
$$
Income_{it} = \alpha_i + \beta_i \cdot Year_t + \varepsilon_{it}
$$

2023年预测值：
$$
\widehat{Income}_{i,2023} = \hat{\alpha}_i + \hat{\beta}_i \cdot 2023
$$

**要求**：该县需要2018-2022年连续5年有城乡收入数据（共975个县满足）

## 三、插补对实证分析的影响评估

### 3.1 潜在增益

| 指标 | 当前(2008-2022) | 插补后(2008-2023) | 变化 |
|------|-----------------|-------------------|------|
| 观测值 | 15,424 | ~16,399 | +6.3% |
| 年份跨度 | 15年 | 16年 | +1年 |
| 改革后长期观测 | 有限 | 增加 | 正向 |

### 3.2 潜在风险

| 风险 | 程度 | 说明 |
|------|------|------|
| 插补误差 | 低 | MAPE仅1.2%，但仍引入噪声 |
| 方差低估 | 中 | 插补值被当作真实值，标准误偏小 |
| 测量误差偏误 | 中 | 被解释变量存在误差会导致attenuation bias |
| 改革效应信息增益 | **有限** | 2023年无新改革，处理效应边际信息量小 |

### 3.3 对计量分析的具体影响

#### 对假说1（公平效应）的影响

```
优点：
- 增加改革后长期效应的观测值
- 可检验改革效应是否持续

缺点：
- 城乡收入比是被解释变量，插补会引入测量误差
- 可能导致系数向零偏误（attenuation bias）
- 不增加平行趋势检验的改革前期观测
```

#### 对假说4（机制检验）的影响

```
中介变量（财政能力、公共服务）2023年数据完整
但被解释变量插补会影响第二步回归的估计精度
```

## 四、专业建议

### 4.1 核心结论

**不建议插补2023年城乡收入数据用于主回归分析**，理由如下：

1. **信息增益有限**
   - 2023年没有新的改革发生，不增加处理效应的边际信息
   - 仅增加6.3%的观测值，对估计效率提升有限
   - 不增加平行趋势检验所需的改革前期观测

2. **引入测量误差风险**
   - 被解释变量（城乡收入比）的测量误差会导致attenuation bias
   - 即使MAPE仅1.2%，对显著性边缘的结果可能有影响

3. **结果稳健性存疑**
   - 审稿人可能质疑插补数据的可靠性
   - 需要额外解释插补方法的合理性

### 4.2 替代方案

#### 方案A：不插补（推荐）

维持当前2008-2022年样本，理由：
- 样本量已足够（15,424观测值）
- 避免引入测量误差
- 结论更加稳健可信

#### 方案B：稳健性检验（如需要）

如果审稿人要求，可将插补后的2023年数据用于**稳健性检验**：
- 在主表中报告2008-2022年结果
- 在附录中报告2008-2023年（含插补）结果
- 比较两者系数是否一致

#### 方案C：机制检验的补充

2023年的财政、公共服务数据是完整的，可以：
- 单独分析2023年改革县与非改革县的财政差异
- 作为机制检验的补充证据（描述性分析）

### 4.3 如果必须插补，推荐方法

若坚持要插补2023年数据，建议采用**线性外推法**并做以下处理：

```python
# 插补步骤
1. 筛选2018-2022年连续5年有城乡收入数据的县（975个）
2. 对每个县分别拟合线性趋势
3. 外推至2023年
4. 计算城乡收入比 = 城镇收入预测值 / 农村收入预测值

# 稳健性处理
5. 标记插补观测（imputed = 1）
6. 在回归中加入 imputed × D 交互项，检验插补是否影响结果
7. 报告排除插补样本的结果作为对照
```

## 五、总结

| 项目 | 建议 |
|------|------|
| **主分析** | 使用2008-2022年真实数据，不插补 |
| **稳健性检验** | 可选择性报告含2023年插补数据的结果 |
| **插补方法** | 如需插补，使用线性外推法（MAPE≈1.2%） |
| **报告策略** | 主表用真实数据，附录报告插补结果对比 |

**核心原则**：宁可样本量略小，也要保证数据质量和结果可信度。当前15,424个观测值已足够支撑稳健的实证分析。
