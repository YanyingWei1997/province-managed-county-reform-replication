## 二、变量说明

### 2.1 标识变量

| 变量名 | 说明 | 类型 |
|-------|------|------|
| year | 年份 | 整数 |
| province | 省份名称 | 字符串 |

| county_code | 区县代码（6位） | 整数 |

### 2.2 核心解释变量（改革变量）

| 变量名 | 说明 | 取值 | 非空率 |
|-------|------|------|-------|
| **D** | 省管县改革虚拟变量 | 改革当年及之后=1，否则=0 | 100% |
| **D1** | 扩权强县改革虚拟变量 | 扩权强县改革后=1 | 100% |
| **D2** | 县财省管改革虚拟变量 | 县财省管改革后=1 | 100% |
| reform_year | 首次改革年份 | 1988-2019 | 64.4% |
| D1_year | 扩权强县改革年份 | 1992-2016 | 27.1% |
| D2_year | 县财省管改革年份 | 1988-2019 | 51.5% |

**改革变量构建逻辑**：
- D1、D2为省管县改革的两种模式
- D = max(D1, D2)，即只要实施任一改革，D=1
- 对于同时实施两种改革的县，reform_year取较早的改革年份

### 2.3 被解释变量（经济增长指标）

| 变量名 | 说明 | 单位 | 非空率 | 均值 | 标准差 |
|-------|------|------|-------|------|-------|
| **gdp_growth_pc** | 人均GDP增长率（核心） | % | 67.4% | 14.04 | 13.30 |
| gdp_growth | GDP增长率 | % | 93.7% | 12.25 | — |
| **ln_gdppc** | 人均GDP对数 | — | 72.2% | 9.65 | 1.02 |
| ln_gdp | GDP对数 | — | 98.2% | — | — |
| gdp | 地区生产总值 | 万元 | 98.2% | — | — |
| gdppc | 人均地区生产总值 | 元 | 72.2% | — | — |

**变量构建说明**：
- `gdp_growth_pc = (gdppc_t - gdppc_{t-1}) / gdppc_{t-1} × 100`
- 极端值处理：增长率超过300%或低于-70%视为异常，设为缺失

### 3.1 核心变量非空率

| 变量类型 | 变量 | 非空率 |

| 中介变量 | ln_fiscal_exp_pc | 99.5% |
|  | fiscal_autonomy | 99.6% |
| 控制变量 | primary_ratio | 98.2% |
|  | ln_pop | 99.6% |
|  | gov_scale | 97.9% |

### 3.2 数据缺失处理

1. **人均GDP**：由于部分年份人均GDP原始数据缺失，非空率为72.2%。在回归分析中建议使用ln_gdp（98.2%）作为稳健性检验。

2. **极端值处理**：
   - GDP增长率：超过300%或低于-70%设为缺失
   - 财政自主度：超过1.5设为缺失（可能为数据错误）
   - 政府规模：超过200%设为缺失

3. **时间序列特性**：GDP增长率为一阶差分指标，因此2000年观测值为缺失。

### 3.3 改革匹配说明

- 改革名单来源：手工收集各省省管县改革政策文件
- 匹配方式：按"省份+县名"精确匹配
- 匹配成功率：990/1537 = 64.4%的县匹配到改革信息
- 未匹配县视为非改革县（控制组）

## 五、使用建议

### 5.1 基准回归变量选择

**被解释变量**（二选一）：
- 首选：`gdp_growth_pc`（人均GDP增长率）
- 备选：`ln_gdppc`（人均GDP对数，用于稳健性检验）

**核心解释变量**：
- 基准模型：`D`（任一改革）
- 分类模型：`D1`（扩权强县）+ `D2`（县财省管）

**控制变量**：
- 必选：`primary_ratio`, `secondary_ratio`, `ln_pop`, `gov_scale`
- 固定效应：县级固定效应（county_code）+ 年份固定效应（year）

### 5.2 中介效应检验变量

**中介变量**：
- `ln_fiscal_exp_pc`（人均财政支出对数）
- `fiscal_autonomy`（财政自主度）

### 5.3 异质性分析

**分组变量**：
- 按发展水平：`high_development`
- 按产业结构：`high_agriculture`
- 按地区：`region`（东/中/西）
- 按行政等级：`is_county_city`

### 5.4 事件研究法

**基准组**：`event_m1`（改革前1期）

**事件时间变量**：`event_m6plus`, `event_m5`, ..., `event_m2`, `event_0`, `event_p1`, ..., `event_p10plus`

## 七、平行趋势检验说明

### 7.1 图1：平行趋势检验

**文件位置**：`/results/图1_平行趋势检验.png`

**检验目的**：验证双重差分模型的平行趋势假设，即在改革实施前，处理组与控制组的经济增长路径具有可比性。

### 7.2 检验方法

基于论文第6页的方法论，采用**PSM-DID + 初始条件×时间趋势控制 + 累积效应框架**：

| 方法组件 | 说明 |
|---------|------|
| **倾向得分匹配(PSM)** | 基于初始人均GDP、产业结构、人口规模、初始增长率进行1:1最近邻匹配（卡尺=0.05） |
| **初始条件×时间趋势** | 引入Xi,0 × t交互项控制由初始禀赋差异引发的异质性增长路径 |
| **一阶差分估计** | 使用GDP增长率消除固定趋势，估计即时效应 |
| **累积效应转换** | 将即时效应累积为水平效应，展示改革的长期影响 |
| **固定效应** | 省份×年份固定效应 + 聚类稳健标准误（县级聚类） |

### 7.3 检验结果

**事件研究回归模型**：
$$lnGDPPC_{it} = \alpha + \sum_{k \neq -1} \delta_k D_{it}^k \times Treated_i + X_{it}\gamma + \mu_i + \lambda_t + \varepsilon_{it}$$

**累积效应结果**：

| 时期 | 系数 | 标准误 | p值 | 95%置信区间 | 包含0 |
|------|------|--------|-----|------------|-------|
| t=-5 | -0.0151 | 0.0193 | 0.434 | [-0.053, 0.023] | **是** |
| t=-4 | -0.0117 | 0.0157 | 0.456 | [-0.043, 0.019] | **是** |
| t=-3 | -0.0027 | 0.0134 | 0.843 | [-0.029, 0.024] | **是** |
| t=-2 | 0.0024 | 0.0104 | 0.814 | [-0.018, 0.023] | **是** |
| t=-1 | 0 | — | — | 基准期 | — |
| t=0 | 0.0155 | 0.0085 | 0.069 | [-0.001, 0.032] | 是 |
| t=+1 | 0.0165 | 0.0135 | 0.220 | [-0.010, 0.043] | 是 |
| t=+2 | 0.0301 | 0.0181 | 0.098 | [-0.006, 0.066] | 是 |
| t=+3 | **0.0463** | 0.0202 | **0.022** | [0.007, 0.086] | **否** |
| t=+4 | **0.0478** | 0.0223 | **0.032** | [0.004, 0.091] | **否** |
| t=+5 | 0.0389 | 0.0239 | 0.103 | [-0.008, 0.086] | 是 |

### 7.4 检验结论

**平行趋势假设：✓ 满足**

- 改革前各期（t=-5至t=-2）的95%置信区间**全部包含0**
- 系数接近0且不显著，表明处理组与控制组在改革前增长路径可比

**改革效应：✓ 显著**

- 改革后系数呈现**递增趋势**
- t=+3和t=+4期系数显著为正（p<0.05）
- 累积效应在改革后3-4年达到峰值（约4.8%）
